Despliegue funcionando

Este proyecto salió de mi computador y llegó a Internet siguiendo el flujo completo:

  1. Proyecto creado en local desde la terminal
  2. git init y commit del código
  3. git push a GitHub
  4. La plataforma detecta la nueva versión y publica sola

Cada vez que haga un push, esta página se actualiza sin que yo toque nada más.
